# ✈️ Airport Data Analytics Dashboard

## 📊 Project Overview
This project is a comprehensive **Data Analytics Dashboard** built in Microsoft Excel. It analyzes aviation data to provide actionable insights into flight operations, passenger demographics, and revenue performance. The dashboard processes over **366,000 passenger records** across **104 cities**, offering a high-level view of airline health and operational efficiency.

## 🚀 Key Features
* **Interactive Slicers:** Dynamic filtering by Month, Day of the Week, Aircraft Type, and Weekday/Weekend status.
* **Financial Tracking:** Analysis of revenue streams totaling **7.87 Billion** (local currency).
* **Operational KPIs:** Monitoring of 33,121 total flights, tracking arrivals, cancellations, and delays.
* **Seating Analysis:** Deep dive into aircraft capacity and class distribution (Economy, Business, and Comfort).

## 📈 Dashboard Insights

### 1. Financial Performance
The airline sees a significant peak in **July**, with revenue reaching **1.32 Billion**. 
* **Economy Class:** Generates the bulk of revenue (~70%).
* **Business Class:** Contributes ~26% of revenue despite lower passenger volume.
* **Weekday vs. Weekend:** Operations are heavily skewed toward weekdays, which generate over **70%** of the total revenue.

### 2. Fleet & Capacity
The dashboard identifies the **SU9** as the primary workhorse of the fleet, accounting for the highest seat count (**71,346**).
| Aircraft Code | Total Seats |
| :--- | :--- |
| **SU9** | 71,346 |
| **773** | 43,196 |
| **CR2** | 32,676 |
| **763** | 29,530 |

### 3. Operational Health
With a **95%+ success rate** for scheduled vs. arrived flights, the operational efficiency is high. The dashboard tracks:
* **Arrived:** 16,707
* **Cancelled:** 414
* **Delayed:** 41

## 🛠️ Tools & Tech Stack
* **Microsoft Excel:** Advanced Data Visualization & Dashboard Design.
* **Power Query:** Used for data cleaning and transformation.
* **Pivot Tables & Pivot Charts:** For multi-dimensional data aggregation.
* **Slicers & Timelines:** To create an interactive user experience.
